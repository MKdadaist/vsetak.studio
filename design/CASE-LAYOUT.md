# Вёрстка кейсов

## Админка экранов: http://localhost:3210/admin

Работает только при `npm run dev` (в сборку и на сайт не попадает).

- Слева список кейсов, справа экраны листалки выбранного кейса.
- У каждого экрана выбирается схема (миниатюры над экраном), экраны можно двигать ↑ ↓ и удалять, «+ Добавить экран» — новый.
- Картинки перетаскиваются из Finder прямо в ячейки; несколько файлов разом заполняют свободные ячейки экрана.
- Картинку внутри ячейки можно двигать мышью — так выбирается кадр. За ⠿ ячейки меняются местами, в том числе между экранами.
- В пустой ячейке есть «ссылка» — для лендинга в iframe или видео .mp4.
- «Сохранить»: картинки режутся под пропорции ячеек, переводятся в WebP (`public/media/<кейс>/`), экраны пишутся в `app/case-screens.json`, сайт обновляется сразу. Исходники хранятся в `public/media/<кейс>/src/`, устаревшие нарезки удаляются.

Схемы экранов — `app/case-layouts.json`. Экран на сайте ограничен высотой окна: первый экран кейса (шапка, заголовок, картинки) помещается на ноутбуке без прокрутки.

Страница кейса — упорядоченный список блоков `blocks` в `app/cases.ts`.
Если у кейса нет `blocks`, страница собирается по умолчанию:
`hero → gallery → facts → sections`.

## Эскиз в InDesign

Шаблон создаёт скрипт `case-template.jsx`
(панель Scripts; файл кладётся в `~/Library/Preferences/Adobe InDesign/Version 21.0/en_GB/Scripts/Scripts Panel`).
Документ сохраняется в `~/Documents/_Porfolio/_Сборка портфолио/Шаблон кейса vsetak.indd`.

- Одна полоса — один экран 1440×900 px. Сетка: 12 колонок, поля 32 px, средник 20 px.
- Блоки идут сверху вниз; горизонтальное положение задаётся колонками.
- Главная вертикаль — 4-я колонка: с неё начинаются роль в фактах, текст описания и узкие блоки.
- Имя фрейма в панели Layers = тип блока. Если фрейм не назван, тип определяется по положению и содержимому.
- Для лендинга в iframe ссылка пишется в Script Label фрейма.

## Типы блоков

| Имя фрейма | Блок | Колонки |
|---|---|---|
| `hero` | заголовок и лид кейса | 1–7 и 8–12 |
| `facts` | клиент, год, роль (в одну строку), статус, ссылка | 1–2, 3, 4–8, 9–12 |
| `gallery` | листалка: картинки, видео, лендинг | вся ширина |
| `sections` | Задача / Решение / Результат; врезка справа (награда, отзыв) | 1–3 и 4–10, врезка 9–12 |
| `media-full` | одно медиа | 1–12 |
| `media-wide` | одно медиа | 4–12 |
| `media-embed` | лендинг в iframe | 1–12 |
| `grid-2`, `grid-3` | сетка картинок | 2 или 3 в ряд |
| `text` | абзац с необязательным заголовком | 4–10 |
| `quote` | цитата и автор | 4–10 |
| `divider` | линия-разделитель | 1–12 |

На телефоне все блоки встают в одну колонку, `grid-3` — в две.
